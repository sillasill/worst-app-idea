A one-sentence pitch for the worst, most useless app imaginable, entered in make.fun's "The Worst App Idea Ever Pitched" bounty. The program prints the pitch and writes it to `entry.txt` — a product that sounds real, a founder who sounds certain, and a function nobody on earth needs.

## Run it

```sh
python3 main.py
```

The pitch is written to `/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to write it elsewhere, e.g. `MAKEFUN_OUTPUT_DIR=./output python3 main.py`).
